# Multi-Source Research Agent

An AI-powered research agent that automatically searches the web, reads articles and generates structured reports.

## Features
- 🔍 Multi-source web research via Tavily
- 🧠 Powered by Gemini 2.5 Flash + Groq Llama 3.3
- 📄 PDF report generation
- 🤖 Built with LangGraph

## Tech Stack
- LangGraph + LangChain
- Streamlit
- Tavily Search API
- ReportLab

# Research Agent — Flow Documentation

## Overview
This agent automatically researches any topic by searching
multiple web sources, reading content and generating a
structured report.

## Architecture

### State (ResearchState)
The shared notebook that flows through all nodes:
- `topic` → research topic entered by user
- `questions` → 4 sub-questions generated by LLM
- `search_results` → URLs found by Tavily
- `scraped_content` → clean text from webpages
- `iterations` → loop counter (max 3)
- `final_report` → finished report written by LLM
- `model_choice` → "gemini" or "groq"

## Nodes

### Node 1: plan_research
- **Tool:** Gemini 2.5 Flash or Groq Llama 3.3
- **Input:** topic
- **Output:** 4 specific research questions
- **Purpose:** Break vague topic into focused questions

### Node 2: search_web_node
- **Tool:** Tavily API
- **Input:** 4 questions
- **Output:** 8 URLs with snippets (2 per question)
- **Purpose:** Find relevant sources on internet

### Node 3: scrape_pages_node
- **Tool:** requests + BeautifulSoup
- **Input:** 8 URLs
- **Output:** clean text from each page
- **Purpose:** Read full content from each URL

### Router: should_continue
- **Type:** Conditional edge (not a node)
- **Logic:** if scraped >= 6 OR iterations >= 3 → done
- **Purpose:** Control the research loop

### Node 4: synthesize
- **Tool:** Gemini 2.5 Flash or Groq Llama 3.3
- **Input:** all scraped content + topic
- **Output:** structured research report
- **Purpose:** Write professional report from sources

## Flow Diagram

```
START
  ↓
plan_research
  ↓
search_web_node
  ↓
scrape_pages_node
  ↓
should_continue()
  ↓              ↓
NOT ENOUGH     ENOUGH
DATA           DATA
  ↓              ↓
search_web_node  synthesize
(loop back)      ↓
                END
```
